Projects, sanitized for daylight.

01 / Geospatial Optimization

Camera Placement Optimization

Python · APIs · Geospatial · Scoring

Built a Python pipeline that ranks candidate intersections by traffic volume, road class, and inter-camera coverage overlap — surfacing the placements that maximize detection per dollar spent. Public sanitized repo demonstrating the technique on open data.

View on GitHub Public repo · open data
02 / Descriptive Analytics

Indecent Exposure Records — Descriptive Analysis

Python · pandas · Statistical reasoning · Honest reporting

The request was a person-by-person re-offense prediction. The data — 34 unique individuals across 5 years — couldn't honestly support that. Produced an aggregate descriptive analysis instead: volume trend, repeat-appearance rate, age distribution, co-occurring charges, seasonality, and a hex-binned geographic view. Documented why a predictive model on this dataset would be statistical theater.

View report Aggregate report · no PII

06 / Red-Team Lab

ATM Jackpotting — Authorized Lab Analysis

CVSS v3.1 · MITRE ATT&CK · PTES / NIST 800-115

Red-team lab exercise against a vendor-decommissioned ATM simulator on an air-gapped network. Tested five attack-vector classes (black-box, malware, network, card-layer, insider), produced 33 CVSS-scored findings, and quantified mitigation effectiveness — full-disk encryption and application allowlisting each cut attack success by 60+ points.

Lab report & findings Authorized lab · educational

Case-tied · confidential
08 / Public Records

OpenOversight Audit & OPSEC Review

FOIA · Metadata · Lucy Parsons Labs · OPSEC

Two-part analysis: (1) audited the OpenOversight Burlington dataset for completeness — 107 officers, 110 assignments, 98 salary records, 7 incidents, 0 narratives. (2) Reviewed how the same lawfully-released data creates a downstream OPSEC surface: spear-phishing personalization, pretext-calling fodder, and impersonation risks for ranked personnel.
